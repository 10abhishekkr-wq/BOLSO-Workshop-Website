Build a complete, professional and visually attractive workshop website for BOLSO – Startup Business.

BOLSO is a fabric-painting teaching/workshop brand. It originally focused on customized fabric painting on T-shirts, bags and other fabrics, but now focuses on teaching students how to create beautiful, soft and wearable fabric paintings.

STRICT TECHNOLOGY REQUIREMENT

Use ONLY:

- PHP
- MySQL
- HTML5
- CSS3
- JavaScript
- Bootstrap

Use PHP as the backend and MySQL as the database.

Use PHP Sessions for authentication.

The project must be compatible with a standard Apache + PHP + MySQL server.

DO NOT use:

- React
- TypeScript
- Vite
- Node.js
- Supabase
- Laravel
- Python
- Any other framework or backend technology

Keep the code simple, clean and easy to deploy on a PHP hosting server.

BOLSO

Tagline:

Art, Emotion, Fashion.

- Cream

- Deep blue
- Green
